# RJ-Creation
📦 R J Creation – Web Application
A full-stack, responsive web application developed for R J Creation, a parts manufacturing company.
The platform enhances workflow efficiency by providing clients and users with seamless access to company information, products, and services.

🚀 Tech Stack
Frontend:
React.js
Tailwind CSS
Lucide-React Icons

Backend:
Node.js
Express.js
MongoDB
JSON Web Token (JWT)
Nodemailer

🎯 Project Goal
To build a modern, responsive, and user-friendly platform that:
Showcases the company's products and services
Improves client–company interaction
Enhances brand visibility
Streamlines inquiries using automated mailing and authentication systems

✨ Features
🔹 Public Features
Responsive and modern UI
Company overview & product catalog
Contact form with email notifications
Smooth navigation with reusable UI components

🔹 Admin Features
Secure login with JWT authentication
Product management (Add / Edit / Delete)
Dashboard for controlling site content
Email alert system using Nodemailer
